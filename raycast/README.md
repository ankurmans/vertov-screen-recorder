# Vertov for Raycast

- **Search Recordings**: your recordings, newest first. Enter copies the link, the second action opens it.
- **Start Recording**: opens the recorder.

Set your API key (starts with `rk_`, made in Vertov settings) in the extension preferences. Leave Server empty unless you self-host.

```bash
npm install
npm run dev
```

The icon is `assets/command-icon.png`, copied from the Vertov store assets.
